# Мок-слой данных (`src/data/`)

Единый источник данных прототипа. **Это не бэкенд** — всё живёт в браузере (React-состояние + `localStorage`, ключ `cryptovps-demo-v1`).

| Файл | Что внутри |
|---|---|
| `types.ts` | форма данных: сервер, событие, операция, SSH-ключ, сценарий |
| `catalog.ts` | справочники из макетов: ОС, регионы, тарифы, сети оплаты, лимиты пополнения |
| `seed.ts` | стартовые данные трёх сценариев: `demo` (как в макетах), `empty` (новый пользователь), `low` (баланс на ~6 дней) |
| `store.tsx` | `AppDataProvider` + `useApp()` → `{ data, actions }`; таймер завершения деплоя/перезагрузки/переустановки |
| `mockApi.ts` | задержки «сети» и случайный сбой создания сервера (25%) |
| `derive.ts` | расход, прогноз баланса, пороги 14/7 дней, возврат при удалении |
| `validation.ts` | правила форм: имя сервера, сумма пополнения |
| `format.ts` | деньги, даты («Сегодня, 14:32»), склонения |

## Действия (`actions`)

`createServer` · `deleteServer` · `rebootServer` · `reinstallServer` · `setServerPower` · `rebootAll` · `addSshKey` · `topup` · `setScenario`

Экраны меняют данные только через них — напрямую `data` не правят.

## Как тестировать краевые случаи

- **Сценарии** — меню аккаунта в шапке кабинета (клик по `anton@mail.ru`): «Демо-данные», «Новый пользователь», «Низкий баланс».
- **Сбой создания** — выпадает случайно в 1 из 4 попыток; на экране — баннер «Сервер не создан» + «Повторить».
- **Истечение курса** — `/billing/topup?ttl=10` (таймер на 10 секунд вместо 30 минут).
- **Несуществующий сервер** — `/servers/любое-имя`.
- **Сброс** — сменить сценарий на «Демо-данные».
