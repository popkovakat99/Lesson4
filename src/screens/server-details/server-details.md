# ServerDetails

- **Figma:** `Screen/ServerDetails` (`91:241`), страница Screens
- **Роут:** `/servers/vpn-ams-01`
- **Из базы:** `Tab` (вкладки, state active/default), `Badge` (success), `Button` (secondary + иконки), `Breadcrumb` (через PageHeader)
- **Общие блоки экранов:** `AppHeader`, `PageHeader`, `EventList` + `EventRow`
- **Локальные блоки** (`parts/`): `ConfigItem` (пункт конфигурации), `LoadMeter` (полоса нагрузки), `MetricChart` (карточка метрики с графиком)
- **Кандидаты на вынос в базу:** `EventRow` (уже общий с Dashboard), переключатель периодов `1ч / 24ч / 7д / 30д` (похож на сегмент-контрол, в базе такого нет)
- **Mock:** все значения статикой из макета. Графики — SVG-плейсхолдеры формы линии, не данные. Вкладки не переключаются.
- **Раскладка:** ConfigBlock — wrap с gap 64; полосы нагрузки и графики — авто-сетки (графики 2×2 → в колонку на узком экране); TabsRow прокручивается по горизонтали.
- **Отличия от макета:**
  - полоса RAM в Figma шире своего контейнера (397 из 296px) — в коде 62% ширины, как подписано;
  - заливка/линия графиков в Figma прибиты `#2563EB` — в коде через `--surface-action-primary` (тот же accent-500);
  - gap полос нагрузки в Figma привязан к токену размера шрифта `size-4xl` (48) — в коде `--space-12` (48).
